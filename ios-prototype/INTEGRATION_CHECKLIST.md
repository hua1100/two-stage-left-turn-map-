# 整合測試檢查清單

## 📋 概述

本檢查清單用於確認所有模組已正確整合，並且 App 功能正常運作。

### 資料服務整合

- [ ] **IntersectionDataService 載入**
  - [ ] App 啟動時自動載入 121 個路口
  - [ ] Console 顯示「✅ 成功載入 121 個路口資料」
  - [ ] 驗證方式：查看 Xcode Console 輸出

- [ ] **IntersectionDataService 查詢**
  - [ ] `intersections` 屬性包含 121 個元素
  - [ ] `allDistricts()` 回傳 12 個行政區

  - [ ] 驗證方式：在 MapView 中測試搜尋功能

- [ ] **資料快取機制**
  - [ ] 首次載入後，後續存取使用快取
  - [ ] Console 顯示「✅ 從快取載入 121 個路口」
  - [ ] 驗證方式：重啟 App 並查看 Console

### 使用者偏好設定整合

- [ ] **UserPreferences 初始化**

  - [ ] Console 顯示「✅ 使用者偏好設定已載入」

  - [ ] 驗證方式：查看 App 啟動時的 Console 輸出

- [ ] **設定持久化**

  - [ ] 測試項目：

    - [ ] 語速設定
    - [ ] 音量設定
    - [ ] 警示距離
    - [ ] 方向容許誤差
    - [ ] 最小警示間隔
  - [ ] 驗證方式：在設定頁面調整參數，重啟 App 後檢查

- [ ] **設定即時生效**
  - [ ] 調整語速後，測試語音立即使用新語速
  - [ ] 調整音量後，測試語音立即使用新音量
  - [ ] 驗證方式：在設定頁面調整參數後立即測試語音

### 地圖與位置服務整合

- [ ] **地圖顯示使用者位置**

  - [ ] 標記位置在台北市範圍內
  - [ ] 標記可以點擊
  - [ ] 驗證方式：縮放地圖查看所有標記

  - [ ] 顯示座標資訊

### 語音與設定整合

- [ ] **語音測試功能**

  - [ ] 關閉語音後，測試語音不播放

  - [ ] 語音不中斷導航語音（僅降低音量）
  - [ ] 驗證方式：實地路測

  - [ ] 從南往西接近路口：✅ 有警示

- [ ] **重複警示防護**

  - [ ] 30 秒後再次接近，可以再次警示
  - [ ] 驗證方式：來回通過同一路口
